# Analog catalog guidance

For Analog work, use the relevant sections of [the catalog policy](../../../docs/analog/README.md). It owns inclusion, curation and the domain boundary; [the implementation contract](../../../docs/analog/IMPLEMENTATION_SPEC.md) owns Scope, data, activity and presentation behavior. Read the affected contract sections when changing those behaviors.

For AI-development classification or badge changes, use [the shared provenance policy](../../../docs/AI_BUILT_REVIEW.md#shared-policy). For activity refreshes or previous project decisions, consult the relevant [implementation notes](../../../docs/analog/IMPLEMENTATION_NOTES.md). The [research seed](../../../docs/analog/RESEARCH_SEED.md) is historical candidate material, not current evidence or Golden inclusion guidance.
