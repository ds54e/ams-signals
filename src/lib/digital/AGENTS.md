# Digital catalog guidance

Applies to Digital content, activity, implementation, tests and docs, including associated sibling paths routed from the root.

Use [Digital rules](../../../docs/digital/README.md) for domain scope and schema differences. Use relevant sections of the [shared catalog contract](../../../docs/catalog/CONTRACT.md) for curation, data, activity or index behavior, not every section for every edit. Shared catalog changes also use the other domain guide.

For development-provenance decisions use [the shared policy](../../../docs/AI_DEVELOPMENT.md). Current decisions and sources live in project frontmatter and Markdown notes; current captures live in activity JSON. The [catalog-refresh skill](../../../.agents/skills/ams-signals-catalog-refresh/SKILL.md) is only for recapturing activity, not general catalog edits. Superseded investigations are historical context, not additional instructions.
