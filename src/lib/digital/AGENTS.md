# Digital catalog guidance

For Digital work, use the relevant sections of [the catalog policy](../../../docs/digital/README.md). It owns inclusion, curation and the domain boundary; [the implementation contract](../../../docs/digital/IMPLEMENTATION_SPEC.md) owns Scope, data, activity and presentation behavior. Read the affected contract sections when changing those behaviors.

For AI-development classification or badge changes, use [the shared provenance policy](../../../docs/AI_BUILT_REVIEW.md#shared-policy). For activity refreshes or previous project decisions, consult the relevant [implementation notes](../../../docs/digital/IMPLEMENTATION_NOTES.md).
