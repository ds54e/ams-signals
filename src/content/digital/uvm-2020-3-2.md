### Implementation and scope

The downloaded official archive identifies itself as 1800.2 2020.3.2 and contains the reference SystemVerilog library, DPI sources, compatibility package and release documentation. UVM components, phasing, sequences, TLM and register models provide conventional Verification infrastructure. Its README explicitly documents deviations and implementation-specific/compatibility APIs; it is not a blanket claim of exact standard parity. [Official source kit](#source-release-code).

The kit includes optional four-state register data and regex/register lookup optimizations with documented compatibility or memory/runtime tradeoffs. Simulator and DPI requirements follow the tool vendor's supported setup. The catalog inspected the archive and release notes, but did not execute a simulator conformance suite. [Release implementation and limits](#source-release-code).
